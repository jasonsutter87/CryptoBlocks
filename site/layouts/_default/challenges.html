How Challenges Work

🎨

Read the Goal

Each challenge tells you what output to produce. Figure out which blocks to use and how to connect them.

🧩

Build & Check

Snap blocks together and hit Check Solution. If the output matches, you pass. Hints are available if you get stuck.

⭐

Earn Stars

Each challenge has a par (block count). Match it for 3 stars. Use fewer blocks and challenge yourself.
